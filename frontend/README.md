# Frontend Workspace

This space is reserved for the modern local UI (Next.js + Tailwind CSS / React) or Streamlit dashboard.

### Planned Features:
- Drag-and-drop media upload zone (PDF, Markdown, Photos, Audio clips, Videos)
- Real-time search & filter bar
- Multimodal result previewer (Audio player, Image viewer, Video player, Markdown reader)
- AI Chat conversation panel with citation cards linking back to the source media
